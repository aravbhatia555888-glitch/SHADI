```javascript

```

## 💡 Pro Tips

1. **Use native driver** for animations (better performance)
2. **Keep animations under 1 second** (feels snappy)
3. **Add easing functions** (spring, ease-out)
4. **Test on real devices** (animations vary)
5. **Reduce motion** for accessibility
